# Contributing

Bug reports and tested monitor layouts are welcome.

Please include:

- Windows version and GPU/driver family;
- X4 distribution and version;
- physical and effective resolution of each display;
- monitor arrangement and the INI window values;
- `X4TripleScreen.log` with unrelated personal paths removed;
- whether X4 was closed before launching the tool.

Do not upload X4 executables, game assets, saves, crash dumps containing private data, or proprietary third-party DLLs.

Code changes should stay limited to X4 window management. Builds must remain free of network access, telemetry, services, drivers, and automatic privilege elevation.
